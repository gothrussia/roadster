# ROADSTER — лендинг концепт-кара

Премиальный одностраничный лендинг в стиле автомобильных презентаций: чёрный фон, неоновый циан, глассморфизм и интерактивная 3D-модель.

**🔗 Живая версия:** https://gothrussia.github.io/roadster/

## Что внутри

- **3D-родстер собственного дизайна**, собранный из базовых геометрий Three.js: кузов (ExtrudeGeometry по боковому профилю с арками колёс), стеклянная кабина, антикрыло, колёса с неоновыми ободами, световые полосы, неоновый контур кузова.
- **Анимации:** вращение вокруг оси, левитация, наклон за курсором (parallax), «дышащая» подсветка снизу, ~900 неоновых частиц на орбитах.
- **Сценарий скролла:** машина уменьшается и уходит в сторону, уступая место тексту, затем приглушается под карточками.
- **Секции:** hero с огромным заголовком, характеристики со счётчиками, три комплектации, футер с контактами.
- **Настройки в одном месте:** блок `CONFIG` — цвет неона, цвет кузова, яркость свечения, число частиц, скорость вращения. Свет и камера прокомментированы.
- Адаптивность, `prefers-reduced-motion`, пауза рендера в скрытой вкладке, запасной вариант без WebGL.

## Стек

HTML5 · CSS3 · JavaScript · Three.js (CDN). Всё в одном файле `index.html`.
